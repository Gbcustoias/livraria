# 📚 TecBook Bookstore

Sistema de Gestão Comercial desenvolvido em Excel VBA para automatizar processos de uma livraria, incluindo controle de estoque, gestão de usuários, gerenciamento de funcionários e registro de vendas.

---

## 📖 Sobre o Projeto

O TecBook Bookstore foi desenvolvido com o objetivo de aplicar conceitos de automação, lógica de programação e gestão de processos utilizando Excel e VBA.

A solução simula o funcionamento de uma livraria real, permitindo o gerenciamento centralizado de produtos, usuários, funcionários e operações de venda por meio de uma interface intuitiva.

---

## 🎯 Objetivos

- Automatizar processos operacionais
- Centralizar informações da livraria
- Controlar estoque de livros
- Gerenciar usuários e funcionários
- Registrar vendas
- Gerar comprovantes automaticamente

---

## 🚀 Funcionalidades

### Gestão de Livros

- Cadastro de livros
- Atualização de registros
- Pesquisa de títulos
- Exclusão de registros
- Controle de estoque

### Gestão de Funcionários

- Cadastro de funcionários
- Atualização de dados
- Consulta de registros
- Exclusão de registros

### Gestão de Usuários

- Controle de acesso via login
- Gestão de credenciais
- Administração de usuários

### Vendas

- Seleção de múltiplos livros
- Cálculo automático de valores
- Registro dos dados do cliente
- Geração automática de nota fiscal

## ▶️ Como Executar

1. Abra o arquivo `.xlsm`.
2. Habilite a execução de macros no Excel.
3. Utilize o menu principal para acessar as funcionalidades do sistema.
4. Realize cadastros, consultas, alterações, exclusões e vendas por meio da interface.
5. Gere automaticamente as notas fiscais das vendas realizadas.
